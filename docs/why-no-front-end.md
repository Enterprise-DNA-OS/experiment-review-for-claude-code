# A review desk without an application front end

An experiment review is a set of records, checks and decisions. The operator asks for the review, the CLI reads the database, and the result is a private document or a read-only dashboard. No application server is required for local use.

A visual editor gives direct website editing, previews and targeting controls. A mobile app gives immediate access on a phone, while a collaborative screen gives simultaneous editing. This base provides none of those experiences. It also does not deliver variants, assign visitors or collect browser events. It works from aggregate report exports.

The useful standalone job is the decision review: a pre-specified plan, the evidence, the reasons to hold, and the human decision that follows.
